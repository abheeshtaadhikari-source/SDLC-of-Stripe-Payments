# SDLC-of-Stripe-Payments

Repositories overview

This repository contains the Software Development Life Cycle (SDLC) comparative analysis report for Stripe Payment Infrastructure. The report studies how different SDLC models can be applied to the development of a Global Payment Infrastructure and evaluates their suitability based on requirements, risk handling, flexibility, and validation process.

This work is prepared as apart of the Software Engineering course assignment.


Repository Structure

This repository maintains version history of the report using GitHub branching:

NNM24IS005_Taek1.docx — Initial draft version of the SDLC analysis report Final NNM24IS005_Task1.docx — Final reviewed and corrected version after improvements, formatting fixes, and validation updates README.md — Repository description and structure documentation


SDLC Models Covered in the Report

The report includes comparative analysis of the following SDLC models:

• Waterfall Model
• Incremental Model
• Spiral Model

Each model is analyzed with respect to Stripe Payment Model development, including:

• Functional and non-functional requirements
• Requirements engineering process
• Requirements validation strategy
• Challenges in requirement validation

This repository follows a structured version control workflow:

• Initial report uploaded to main branch
• Final revised report uploaded through a separate branch
• Summary Report of the Plagiarism Test on the Final Report


Purpose of the Report

The objective of this report is to:

• Understand SDLC model differences
• Apply SDLC concepts to a Global Payment Infrastructure 
• Compare model suitability for the advanced financial services and money transactions
• Study requirements engineering and validation methods
• Demonstrate structured documentation and version control
